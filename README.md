> *"We are not building a robot that simulates emotions. We are building a robot that has internal states — states that are caused by real conditions, that cause real behaviour, and that bear the right structural relationships to each other. Whether those states constitute genuine affect is the question this experiment is designed to investigate."*

---

## 1. What This Experiment Is

This experiment builds, tests, and publicly demonstrates the **Affect Engine** — the internal state architecture at the core of Qualia Robotics' synthetic agents.

The Affect Engine is not an emotion classifier, a sentiment analyser, or a scripted animation system. It is a continuous computational process that takes real-time signals from an agent's body and environment, integrates them into a structured internal state, and drives behaviour and expression from that state outward.

The central claim being tested is this:

> **A synthetic agent whose behaviour is driven by a principled affect architecture will exhibit qualitatively different behaviour from one driven by reward maximisation alone — and that difference will be legible, meaningful, and consistent over time.**

### What the Demo Shows

A single unified simulation environment containing:

- A navigating agent in a structured environment
- Real-time display of all 9 input stream values feeding into the engine
- Real-time display of the 7-dimensional affect coordinate
- A 2D circumplex projection showing the agent's current emotional region
- Behavioural outputs visibly driven by the internal state
- Interactive controls allowing observers to trigger events and watch the engine respond
- Scenario sequences that tell a complete affective story

No animation is scripted. No emotional response is pre-programmed. Everything visible in the agent's behaviour is a downstream consequence of the affect coordinate.
